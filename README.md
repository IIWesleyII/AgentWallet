# AgentWallet

A responsive, static HTML/CSS recreation of `AgentWallet Dashboard UI.png`.

Open `index.html` directly in your browser. No installation or build step is needed.

- `index.html` contains the dashboard markup and inline SVG icons.
- `styles.css` contains the desktop, tablet, and mobile layouts.
- Navigation jumps to dashboard sections, and the task selector uses native HTML.
- Balances, policies, and transactions are sample data. Wallet connection, agent execution, policy editing, and transaction history actions are disabled placeholders.

No JavaScript, external fonts, packages, or network requests are required.
